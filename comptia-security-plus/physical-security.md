# ​ Lesson 7: Physical Security — CompTIA Security+ (Professor Messer)

This lesson explores **Physical Security**—the foundational layer of information security that protects IT systems through tangible controls. It’s a key part of a defense-in-depth strategy and vital for securing any environment.

---

##  ​ What Is Physical Security?

Physical security includes safeguards that protect environments, equipment, and assets from unauthorized physical access, damage, or interference. It involves:
- Barriers and deterrents (e.g., bollards, turnstiles, locked doors)  
- Surveillance and monitoring (e.g., CCTV, motion sensors)  
- Access validation (e.g., badges, biometrics, vestibules)  
- Environmental protections (e.g., alarms, signage, camouflage)

##  ​ Key Physical Security Controls

| Control Type         | Purpose                            | Examples                                     |
|----------------------|------------------------------------|----------------------------------------------|
| Physical Barriers    | Prevent unauthorized entry          | Bollards, locks, fenced perimeters           |
| Access Controls      | Verify identity before entry        | Badge readers, biometric scanners, vestibules |
| Surveillance & Alarms| Monitor and deter                  | CCTV systems, motion detectors, alarms       |
| Environmental Measures| Mitigate environmental risks        | Signage, camouflage, intrusion detection     |

##  ️Why It Matters

- **Prevents social engineering attacks** where attackers try to bypass digital controls via physical presence.
- **Protects critical infrastructure**, especially servers, data centers, and sensitive equipment.
- **Supports regulatory compliance** and forensics by restricting access and providing audit evidence.
- **Complements digital security**, ensuring physical entry doesn't bypass network protections.

---

##  ️Key Takeaways

- Physical security is the first line of defense—**you can’t secure what you can’t physically access**.
- A multi-layered approach (barriers → access control → surveillance) increases effectiveness.
- Regular testing and updates are important to address evolving threats and weaknesses.
- Integration with IT (e.g., logging badge access) enhances visibility, incident response, and accountability.
