# 📘 Lesson 5: Gap Analysis — CompTIA Security+ (Professor Messer)

This lesson introduces the concept of a **Gap Analysis**, which helps organizations compare their current security posture with desired outcomes or compliance requirements. This process is essential for identifying weaknesses, prioritizing improvements, and meeting industry or regulatory standards.

---

## 🔍 What Is a Gap Analysis?

A **Gap Analysis** is used to:
- Evaluate the difference between where an organization is now and where it needs to be.
- Identify missing controls, outdated practices, or insufficient policies.
- Plan how to close the gap between current and desired security states.

---

## ⚙️ Steps in a Gap Analysis

1. **Define the Target State**  
   - Set the security goals or required standards (e.g., NIST, ISO 27001, PCI-DSS).

2. **Evaluate the Current State**  
   - Review existing controls, documentation, and security implementations.

3. **Identify the Gaps**  
   - Compare current practices to the desired outcome and highlight what’s missing.

4. **Prioritize the Gaps**  
   - Determine which gaps pose the highest risk and should be addressed first.

5. **Develop a Remediation Plan**  
   - Create an action plan to close the gaps with timelines and resources.

---

## 🧾 Real-World Examples

- A retail company evaluates its systems against **PCI-DSS** and discovers missing encryption for stored credit card data.
- A hospital checks its processes against **HIPAA** and finds that user access controls are not consistently enforced.
- An enterprise compares its internal security posture to **ISO 27001** and realizes that it lacks a formal incident response plan.

---

## 📌 Key Takeaways

- Gap Analysis helps improve **security maturity** and **compliance readiness**.
- It provides a structured method to find and fix weaknesses.
- Enables better **risk management** and informed decision-making.
- Should be repeated periodically as threats, technologies, and regulations evolve.
