# 📘 Lesson 6: Zero Trust — CompTIA Security+ (Professor Messer)

This lesson explores the **Zero Trust** security model—a modern approach that assumes **no implicit trust**, whether users are inside or outside the network perimeter. Every access request must be verified to reduce risks in a dynamic, distributed environment.

---

## 🔍 What Is Zero Trust?

Zero Trust security operates on a core principle: **“Never trust, always verify.”**  
Unlike traditional perimeter-based security, Zero Trust treats **every request as untrusted** until proven otherwise, requiring validation of identity, device health, context, and intent.

---

## 🛡️ Core Principles of Zero Trust

1. **Verify Explicitly**  
   - Use strong authentication (e.g., MFA), device validation, and risk-based context analysis.

2. **Use Least Privilege Access**  
   - Grant users minimal access required for tasks and employ just-in-time provisioning.

3. **Assume Breach**  
   - Use segmentation, micro‑segmentation, and continuous monitoring to limit lateral movement.

---

## 🧭 Zero Trust Architecture

- **Strong Authentication & Authorization**  
  - Multi-factor authentication, risk scoring, and adaptive access policies.
- **Device Security**  
  - Enforce device posture checks (e.g., antivirus, OS updates, encryption).
- **Network Segmentation**  
  - Define granular zones to isolate workloads and enforce policies.
- **Continuous Monitoring & Analytics**  
  - Log and inspect traffic in real-time to detect anomalies.

---

## 📌 Why Zero Trust Matters

- **Remote Work & Cloud Adoption**  
  - Users and services operate outside traditional perimeters, calling for identity-centric security.
- **Modern Threat Landscape**  
  - Zero Trust limits damage if a device or account is compromised.
- **Compliance & Risk Reduction**  
  - Encourages visibility and strong access controls—key for regulatory frameworks like NIST and ISO.

---

## ✅ Key Takeaways

- **Zero Trust = default deny + continuous verification.**
- Focus on **identity, device, and context** for every access decision.
- It’s a **moving target**—monitor, reassess, tune policies continuously.
- A powerful framework for modern environments, especially with SaaS, cloud, and remote work.
